# Request-board visual treatment

The request board uses `/assets/almostlegit-hero-broadcast.jpg` as its primary visual anchor. The image shows a dark streaming control room with dual waveform monitors, a microphone, a controller, and a broadcast desk. It is placed behind the first viewport with layered gradients so the left-side headline, request explanation, and controls remain readable.

A subtle scanline overlay keeps the page connected to the Signal Raid broadcast language without overpowering the background. The image is reduced or repositioned at smaller widths, while the text and request controls remain in normal document flow.

The main catalog and public-request columns use translucent graphite surfaces with backdrop blur. This keeps the studio visible around the edges while providing stable contrast for search, filters, status copy, and request actions.

The four story-driven lead cards reuse the bundled deployment-safe imagery. Red Dead Redemption 2 and Kingdom Come: Deliverance II use the western artwork; Grand Theft Auto V uses the broadcast-room artwork; and S.T.A.L.K.E.R. 2 uses the survival artwork. These images are decorative context only and are never used as a substitute for game metadata or creator approval.

The page remains request-first. The headline, catalog section, request buttons, public status panel, creator-application prompt, and no-funds disclosure remain visible above and around the image. The background does not introduce location information or payment language.
